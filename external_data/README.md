# External research data

This directory is ignored by Git. Downloaded datasets and licensed local corpora belong here.

The repository intentionally does **not** redistribute third-party research data unless its redistribution terms are clear.

Supported adapters:

- NDL Aozora furigana corpus: `scripts/prepare_ndl_aozora.py`
- SMART mnemonic datasets (Hugging Face): `scripts/fetch_smart.py`
- A locally obtained pun/paraphrase table: `scripts/prepare_pun_data.py`
- Human-pun / model-generation DPO pairs: `scripts/prepare_dpo_pairs.py`
